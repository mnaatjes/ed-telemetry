# Interface and Boundary Contracts Governance

Governed by OpenAPI 3.1 and AsyncAPI specifications.

---

## 1. Principles

1. **Machine-Readable Schemas:** Contracts authored strictly in standard YAML or JSON.
2. **Contract-First Development:** Interface boundaries must be formalized during Elaboration prior to downstream adapter implementation.
3. **Semantic Versioning:** Interface contracts declare explicit versioning matching semantic releases.
