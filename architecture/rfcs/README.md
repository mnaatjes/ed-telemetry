# Collaborative Engineering RFCs Governance

Used during Inception and Elaboration to evaluate competing technical options, conduct feasibility spikes, and forge consensus prior to binding ADRs.

---

## 1. Directives

1. **Trade-Off Matrix:** Every RFC must analyze at least two viable alternative solutions against explicit evaluation criteria.
2. **Lifecycle:** `draft` -> `review` -> `accepted` (spawning an ADR in `architecture/adr/`) or `rejected`.
